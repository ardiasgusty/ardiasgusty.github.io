JSON Editor

File JSON menjadi sumber data. Setelah mengedit, klik Terapkan JSON. Kamu juga dapat menyimpannya sebagai file .json.

Format yang digunakan adalah array objek: id, domain, provider, loginUrl, startDate, expDate, note. Tanggal gunakan format YYYY-MM-DD.

Pengaturan GitHub Token

Gunakan GitHub Personal Access Token (PAT) untuk menarik dan menyimpan data secara otomatis ke file domain-hosting.json di repositori ardiasgusty.github.io.

Token disimpan lokal di browser Anda. Butuh token klasik dengan hak akses repo atau fine-grained token dengan hak akses write content ke repositori Anda.
